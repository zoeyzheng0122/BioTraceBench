# Source provenance and third-party notices

BioTraceBench was extracted from the paper-bound runtime and verified publication implementation of [biomedical-curation-eab](https://github.com/zoeyzheng0122/biomedical-curation-eab). The source commit and scope are recorded in [docs/source_provenance.json](docs/source_provenance.json). This repository starts an independent publication-code history; earlier development history remains in the upstream repository.

The author-provided PNG and SVG figures are unchanged copies of the manuscript artwork. Embedded figure metadata and notices are preserved. No public reuse license has been assigned to the author-provided code or figures in this private preparation repository.

Third-party Python packages are installed separately under their own licenses. Relevant upstream projects include [NumPy](https://github.com/numpy/numpy), [Pillow](https://github.com/python-pillow/Pillow), [openpyxl](https://foss.heptapod.net/openpyxl/openpyxl), [pypdfium2](https://github.com/pypdfium2-team/pypdfium2), [Tokenizers](https://github.com/huggingface/tokenizers), [setuptools](https://github.com/pypa/setuptools) and [wheel](https://github.com/pypa/wheel). Their source and binary distributions are not vendored here.

Source papers, supplements, data repositories and other scientific materials are handled through the external materials package's provenance and redistribution records. They are excluded from this code repository.

Repository organization was informed by [PrepBench](https://github.com/TsinghuaDatabaseGroup/prepbench), [SemBench](https://github.com/SemBench/SemBench) and [Benchmarking MV-Based Rewriting](https://github.com/edx-h/Benchmarking-MV-Based-Rewriting). These references informed documentation and navigation; no source code was imported from them.
