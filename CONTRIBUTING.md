# Contributing

For a dataset or scoring issue, include the case ID, the file or field in question, and the relevant source or output. For a software issue, include the command, Python version, and observed result.

For a pull request, explain the effect of the change and how you checked it. Run the offline demo and repository tests before submitting. If case files are involved, also check them against the versioned reproduction archive. [Minimal smoke tests](README.md#minimal-smoke-tests)
